0.0: TP Diagnóstico

Consigna

Contestar y definir, con sus palabras, las siguientes preguntas.

Es válido investigar en internet o en distintos medios, pero por favor no copien y peguen definiciones (Prohibido ChatGPT). El objetivo de la actividad no es llenar páginas y páginas de texto, sino poder evaluar cuánto conocen del tema.

El Trabajo Práctico es individual.

Plataformas Móviles

  1. ¿Qué diferencias hay entre un smartphone y un feature phone (o dumb phone)?
  2. ¿Qué diferencias encuentran entre un teléfono móvil (smartphone) y una computadora? ¿Y qué similitudes?
  3. ¿Qué sistema(s) operativo(s) de computadora conocen? ¿Y de smartphones?
  4. ¿Qué es la arquitectura o juego de instrucciones de un procesador?
  5. ¿Cuál es la diferencia entre un lenguaje de programación compilado y un lenguaje de programación interpretado?
  6. ¿Conocen la diferencia entre tipado estático y tipado dinámico de datos?
  7. ¿Conocen la diferencia entre error semántico y error sintáctico?

Tecnologías Web

  1. ¿Qué es HTML? ¿Para qué sirve?
  2. ¿Qué es CSS? ¿Para qué sirve?
  3. ¿Cómo se relacionan CSS y HTML?
  4. ¿Qué es JavaScript?
  5. ¿Qué relación hay entre JavaScript y Java?
  6. ¿Qué es un paradigma en un lenguaje de programación?
    • a. ¿Qué lenguajes de programación conocen?
    • b. ¿Pueden asociar esos lenguajes con su(s) paradigma(s)?
  7. ¿Qué es un estándar o especificación? Dar algunos ejemplos.
  8. ¿Conocen Git? ¿Qué diferencia hay entre Git y GitHub?
