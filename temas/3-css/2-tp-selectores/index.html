3.2: tp-2 (Selectores)

Objetivo

Aplicar estilos básicos a un documento HTML utilizando selectores CSS.

Formato de Entrega

  • Crear un archivo HTML en la ruta tp-2/index.html, con el contenido del HTML inicial.
  • Agregar estilos CSS al documento HTML (usando un archivo .css externo o una etiqueta <style> dentro del documento).
  • Subir todo al repositorio de entregas en GitHub.

Consigna

1. Agregar Archivo CSS

Para este nuevo archivo HTML creado, agregar una hoja de estilos CSS de alguna de las siguientes maneras vistas en clase:

  • Usando un elemento <link> dentro del <head></head> del documento.
  • Usando un elemento <style></style> dentro del documento.

2. Agregar estilos CSS

Dentro de CSS, implementar las definiciones para aplicar los siguientes estilos:

  1. Mostrar todos los párrafos con una fuente sans-serif.
  2. Agregar una regla para definir el color de fondo del documento en rgb(34, 34, 34), y el color del texto en rgb(238, 238, 102).
  3. Mostrar centrado el título principal del documento.
  4. Agregar una regla para mostrar en color #eee todos los títulos del documento.
  5. Agregar un borde inferior color white a todos los elementos <strong>.
  6. Mostrar el fondo gris #444444 y el texto en negrita para todos los elementos con la clase the-force.
  7. Mostrar el texto con color #6666ff para los elementos con la clase light-side, y color #ff3333 para la clase dark-side.
  8. Agregar la regla list-style-type: circle; a los elementos del listado con ID og-trilogy.
  9. Hacer que el título principal cambie de color cuando se pasa el puntero por encima a #ff0.
  10. Hacer que los links visitados cambien a color gray.

Bonus Track

  1. Agregar margin-left al segundo listado de películas.
  2. Agregar margin-top al último elemento del tercer listado de películas.
  3. Hacer que todos los títulos muestren su texto en mayúscula.
  4. Hacer que la primera línea del primer párrafo se muestre color rgb(238, 255, 238).
  5. Mostrar los links sin atributo href en cursiva.
  6. Mostrar de manera alternada el color de fondo de cada uno de los elementos de los listados de películas entre #111 y #333.

Atención:

  • No está permitido el uso de estilos inline.
  • No modificar la estructura de las etiquetas HTML ya existentes.
  • No está permitido el uso de !important.
