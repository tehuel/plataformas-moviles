4.2: tp-8 (Funciones)

Objetivo

Practicar la definición y el uso de funciones en JavaScript.

Formato de Entrega

  • Crear un archivo HTML en la ruta tp-8/index.html, con el contenido del HTML inicial.
  • Subir el archivo al repositorio de entregas.
